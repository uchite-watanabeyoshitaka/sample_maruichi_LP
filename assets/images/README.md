# LP 画像用フォルダ

元LPで使用されていた画像をここに配置すると、`da-replica.html` で表示されます。

## 必要な画像一覧（元のファイル名）

- **ファーストビュー:** `fv01.webp`, `fv01_2.webp`
- **CTAボタン:** `btn.webp`
- **セクション:** `section_02.webp` ～ `section_09.webp`, `section_04_2.webp`, `section_08_2.webp`, `section_08_2_1.webp`
- **お客様の声（顔など）:** `voice01.webp` ～ `voice09.webp`
- **特典:** `tokuten01.webp`, `tokuten02.webp`, `tokuten03.webp`, `tt01.webp`, `tt02.webp`, `tt03.webp`
- **講師:** `instructor.png`（講師紹介の顔写真。円形で表示されます）
- **ヒーロー用:** `hero-speaker.png`（ヒーロー右側に表示する講師写真）

現在はプレースホルダー表示のため、上記を用意しなくてもレイアウトは確認できます。独自LPに変更する際は、ここに画像を入れてパスを合わせてください。
